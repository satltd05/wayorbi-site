# Prompt prêt à donner à Claude Code depuis Antigravity

Tu travailles sur le projet **Wayorbi** présent dans ce dossier. Lis d'abord `README.md` et `docs/CAHIER_DES_CHARGES_WAYORBI.md`, ainsi que le code existant.

**Objectif :** transformer le site vitrine en une expérience web très élaborée, originale, immersive, responsive et accessible, tout en respectant *l'intégralité* du concept Wayorbi.

Consignes :

1. Conserve la vidéo originale du logo et l'identité cyan/bleu/violet. Le site Polarsteps peut inspirer l'exigence visuelle, mais ne copie ni sa mise en page, ni son code, ni ses textes, ni ses médias.
2. Améliore chaque page de manière cohérente : accueil, concept, carnets, atelier, explorer, communauté, Travel DNA, fonctionnalités, bêta, FAQ.
3. Ne transforme pas Wayorbi en simple agence de voyages : c'est un futur réseau social de carnets d'expériences réelles.
4. Priorise la navigation, la clarté du produit, les animations discrètes, les micro-interactions utiles, l'ergonomie mobile, l'accessibilité et la performance.
5. Identifie ce qui est démo locale, projeté et fonctionnel. Ne mens jamais sur une sauvegarde, publication, compte, IA ou donnée réelle.
6. Avant chaque modification, relis les composants concernés ; ne détruis pas les démonstrations déjà fonctionnelles, le logo vidéo ou les données d'exemple.
7. Travaille par étapes testables, lance `npm run lint` et `npm run build` après les modifications, vérifie l'application sur mobile et desktop, et corrige chaque erreur.
8. Pour une application sociale réellement opérationnelle, prépare séparément l'architecture d'authentification, les modèles de données, le stockage médias, les permissions et la sécurité ; ne crée pas de faux backend.

Commence par faire un audit de la version actuelle, puis propose les **trois améliorations visuelles et fonctionnelles ayant le plus d'impact** et implémente-les dans le code de manière complète. Ensuite, avance page par page, avec des tests et un résumé fidèle des changements.
